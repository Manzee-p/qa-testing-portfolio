# QA Testing Portfolio – HelpCenter

Dokumentasi pengujian yang saya lakukan terhadap **HelpCenter**, aplikasi web buatan saya sendiri. Portofolio ini menunjukkan cara saya menyusun test case, mencatat bug, dan memverifikasi perbaikan, bukan pengalaman kerja sebagai QA penuh waktu.

## Tentang Project

HelpCenter adalah sistem berbasis web untuk mengelola laporan dan permintaan internal secara terstruktur, mulai dari pembuatan tiket, penugasan vendor, pemantauan status, hingga penyelesaian laporan.

- **Tech stack:** Laravel, Vue.js, MySQL
- **Peran saya:** Developer sekaligus penguji (self-testing)

## Isi Repository

| File | Keterangan |
|------|------------|
| [Test-Case.md](Test-Case.md) | Skenario pengujian berdasarkan kebutuhan fitur |
| [Bug-Report.md](Bug-Report.md) | Temuan bug dengan langkah reproduksi dan bukti |
| [Testing-Summary.md](Testing-Summary.md) | Ringkasan hasil pengujian dan retest |

## Jenis Pengujian

- Manual functional testing pada aplikasi web
- Form validation testing
- Retest dan regression testing setelah perbaikan bug
- Pengujian REST API dengan Postman
- Validasi data di database dengan query SQL dasar

## Tools

- Google Chrome dan Browser DevTools (Console, Network)
- Postman
- MySQL
- Laravel dan Vue.js (aplikasi yang diuji)
